# DJ Toolkit

Hub educacional para DJs — teoria, tutoriais, recursos e ferramentas.

> Antes de saber o que comprar ou usar, entenda por que aquilo importa.

## Estrutura

- dj/
  - conceitos/ — Teoria: BPM, harmonia, energia, estrutura de set
  - tutoriais/ — Como usar ferramentas, montar sets, entregar pro produtor
  - recursos/  — Pools, softwares, fontes de musica com contexto de cada um
  - setups/    — Faixas de investimento com justificativa de cada escolha

- producao/
  - conceitos/ — DAWs, sintese, arranjo, mixagem de estudio (em construcao)

> Nome provisorio — sera renomeado quando o nome artistico for confirmado.
